Abordagens para Edição Offline (Todas Entidades)

Opção 1: Banco de Dados Robusto (Dexie.js) Recomendado

Criamos um espelho do seu banco de dados Drizzle no navegador usando IndexedDB.

  • Funcionamento: Toda leitura/escrita passa primeiro pelo banco local. Uma fila de sincronização envia as mudanças para o servidor quando há internet.
  • Ideal para: Muitos dados e relações complexas (Projetos > Tarefas > Notas).
Prós:
  • Alta performance (zero lag)
  • Suporta buscas complexas offline
  • Muito estável com muitos dados
Contras:
  • Requer mais código inicial (definir schemas no cliente)

Opção 2: Persistência de Estado (VueUse/Pinia)

Salvamos o estado das suas Pinia Stores diretamente no armazenamento local.

  • Funcionamento: O estado atual do sistema é persistido. Quando volta a internet, o sistema tenta dar "push" no que mudou.
  • Ideal para: Sistemas mais simples ou com poucos dados por usuário.
Prós:
  • Implementação rápida
  • Pouco boilerplate
Contras:
  • Difícil de gerenciar relações entre tabelas
  • Pode ficar lento se o cache crescer muito
